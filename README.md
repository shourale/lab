# Практические работы по Java

Решения практических работ, сгруппированные по учебным блокам. Каждая программа запускается отдельно через свой метод `main`.

## Структура

```text
src/
├── block_1/          — практики → task_N → классы задания
├── block_2/          — практики → task_N → классы задания
└── block_3/          — списки
```

В таблицах перечислены реализованные задания. Отдельного пакета практики 5 нет. Пропуски в нумерации не означают, что представлены все задания соответствующей методички.


Обычно задания находятся в подпакетах `task_N`, где `N` — номер задания в методичке. Например:

```text
src/block_1/practice2/
├── task_1/     — Author, TestAuthor
├── task_4/     — Computer, Shop, TestShop
└── task_9/     — Poker

src/block_2/practice13/
├── task_1/     — операции со строкой
├── task_2/     — Person и инициалы
├── task_3/     — Address
├── task_4/     — Shirt
├── task_5/     — PhoneNumber
└── task_6/     — цепочка слов, words.txt
```

Задания в `block_2.practice9_10` используют общий `Student`, сортировщик и методы одного `main`. Там же находится дата рождения студента для №11.3.

## Запуск в IntelliJ IDEA

1. Открыть проект и выбрать установленный JDK. Текущий код проверен на JDK 23.
2. Открыть нужный класс из таблицы.
3. Нажать зелёный треугольник рядом с методом `main` → **Run**.
4. Старые конфигурации запуска могут ссылаться на прежний пакет. В этом случае запустить класс заново зелёной кнопкой у его `main`.
5. Если программа ожидает ввод, ввести данные в нижней панели **Run** и нажать Enter.

Классы моделей и интерфейсы (`Student`, `Author`, `Nameable` и другие) запускаются через соответствующие проверочные классы, а не отдельно.

## Запуск из терминала

Из корня проекта скомпилировать три учебных блока:

```bash
mkdir -p out
find src/block_1 src/block_2 src/block_3 -name '*.java' > out/sources.txt
javac -encoding UTF-8 -d out @out/sources.txt
```

Запустить выбранный класс, указав пакет и имя без `.java`:

```bash
java -cp out block_1.practice1.task_3.Lab_1
java -cp out block_1.practice2.task_4.TestShop
java -cp out block_1.practice41.task_9.TestFurniture
java -cp out block_2.practice9_10.main
java -cp out block_2.practice13.task_3.ex_3
java -cp out block_2.practice14.task_7.ex_7
java -cp out block_3.Practice17.Task_1.TestStudent
```

Аргументы запуска для первой практики:

```bash
java -cp out block_1.practice1.task_5.Prac_1_3 one two three
```

В IntelliJ эти значения задаются через **Run → Edit Configurations → Program arguments**. Без аргументов программа ничего не выводит.
