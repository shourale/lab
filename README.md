# Практические работы по Java

Решения практических работ, сгруппированные по учебным блокам. Каждая программа запускается отдельно через свой метод `main`.

## Структура

```text
src/
├── block_1/          — основы Java и ООП: практики 1–7, раздел 4.1
├── block_2/          — рекурсия, сортировки, даты, строки: практики 8–14
└── train/            — дополнительные упражнения: методы, объекты, массивы
```

В таблицах перечислены реализованные задания. Отдельного пакета практики 5 нет. Пропуски в нумерации не означают, что представлены все задания соответствующей методички.

## Запуск в IntelliJ IDEA

1. Открыть проект и выбрать установленный JDK. Текущий код проверен на JDK 23.
2. Открыть нужный класс из таблицы.
3. Нажать зелёный треугольник рядом с методом `main` → **Run**.
4. Если программа ожидает ввод, ввести данные в нижней панели **Run** и нажать Enter.

Классы моделей и интерфейсы (`Student`, `Author`, `Nameable` и другие) запускаются через соответствующие проверочные классы, а не отдельно.

## Запуск из терминала

Из корня проекта скомпилировать два учебных блока:

```bash
mkdir -p out
find src/block_1 src/block_2 -name '*.java' > out/sources.txt
javac -encoding UTF-8 -d out @out/sources.txt
```

Запустить выбранный класс, указав пакет и имя без `.java`:

```bash
java -cp out block_1.practice1.Lab_1
java -cp out block_1.practice2.TestShop
java -cp out block_1.practice41.furniture.TestFurniture
java -cp out block_2.practice9_10.main
java -cp out block_2.practice13.ex_3
java -cp out block_2.practice14.ex_7
```

Аргументы запуска для первой практики:

```bash
java -cp out block_1.practice1.Prac_1_3 one two three
```

В IntelliJ эти значения задаются через **Run → Edit Configurations → Program arguments**. Без аргументов программа ничего не выводит.
